连接你的 GitHub 博客

公开文章可以直接浏览和编辑。连接 GitHub 后，即可发布、更新和删除文章。

仓库设置（通常无需修改）
第一次使用：创建仓库专用授权码
  1. 打开 GitHub 授权码设置，按页面提示登录。
  2. 在 Repository access 选择 Only select repositories，只选你的博客仓库。
  3. 将 Repository permissions → Contents 设为 Read and write，选择有效期，然后生成。
  4. 把生成的授权码粘贴到下方。不要发到聊天或写入仓库文件。

仅在自己的设备上勾选。授权码会保存在此浏览器；退出会清除。授权过期或被撤销后需重新连接。不勾选则只保留本页连接。

删除线上文章

将提交删除到 GitHub，网站完成部署后生效。本机草稿和图片保留。

删除本机草稿

只删除此浏览器中的这份草稿及其附件，不会删除 GitHub 上的文章或图片。尚未发布的内容删除后无法恢复，需要保留请先取消并导出备份。

你的写作流程

  1. 左侧自动读取公开仓库中的全部文章，可搜索标题、日期和正文。点击文章开始编辑，或点 ＋ 新建文章。
  2. 首次连接 GitHub 时，可勾选“记住此浏览器”，下次自动连接。
  3. 草稿自动保存在当前浏览器；“保存草稿”不会发布。同一线上版本再次打开时会恢复已有草稿。
  4. 点击“发布到博客”或“更新线上文章”，将文章和新图片一起提交。
  5. 等待 GitHub Pages 部署成功后，在博客查看。可以点击“查看部署进度”。

无图片时导出一份文章文件；有图片时导出压缩包，保留其中的文件夹结构。以后可直接重新打开这些文件继续编辑。

浏览器草稿不是备份，清理浏览器数据或更换浏览器后可能无法找到。请及时导出重要文章。

“导出备份”仍可离线使用。连接采用仓库专用授权码，不是 OAuth 跳转登录；授权码不会写入草稿或项目文件。

若文章已在其他地方修改，系统会阻止覆盖；先导出备份，再重新打开线上版本。复杂模板、表格等内容会使用原文模式。
